## 3. AI Discount System Fix

### Root Cause
Two issues combined:
1. **Backend:** Supabase `approved_discounts` table was empty. RLS policy required `auth.role() = 'authenticated'` but Flask backend uses anon key (role = `anon`). Writes silently fell back to `.approved_discounts.json` file, but reads went to the empty Supabase table → users saw no discounts.
2. **Vercel ephemeral:** Serverless functions reset on cold start, so file-based persistence was lost.

### Architecture (before fix)
```
Admin Approve → tries Supabase INSERT (RLS blocks) → falls back to file
User Read → reads from Supabase (empty) → returns []
```

### Architecture (after fix)
```
Admin Approve → writes to file + Supabase (RLS fixed)
User Read → merges file + Supabase → returns correct list
```

### Changes

**Backend (`backend/app.py` lines 2245-2341):**
- `GET /api/discounts/approved`: Now reads file first (source of truth), then merges Supabase data
- `POST /api/discounts/approve`: Saves to file first, then best-effort Supabase sync
- `POST /api/discounts/dismiss`: Same pattern: file first, Supabase best-effort

**SQL migration (`backend/migrate-fix-discount-rls.sql`):**
```sql
DROP POLICY IF EXISTS "Authenticated users can approve" ON approved_discounts;
DROP POLICY IF EXISTS "Authenticated users can dismiss" ON approved_discounts;

CREATE POLICY "Anyone can approve discounts"
  ON approved_discounts FOR INSERT WITH CHECK (true);
CREATE POLICY "Anyone can dismiss discounts"
  ON approved_discounts FOR DELETE USING (true);

INSERT INTO approved_discounts (event_room_type_key)
VALUES ('BER Months Early Bird-Standard')
ON CONFLICT (event_room_type_key) DO NOTHING;
```

**File (`backend/.approved_discounts.json`):**
- Updated to `["BER Months Early Bird-Standard"]` (removed Deluxe per admin intent)

**Frontend optimization (`src/pages/Rooms.tsx`):**
- Lifted `useDiscountApproval()` from individual `RoomCard` to `Rooms` page — 1 API call instead of N
- `RoomCard` now accepts `isApproved` as a prop

**Commit:** `145cef8`, `d1d6431`, `462a96a`

## 4. RoomDetail Crash Fix

**Problem:** White screen when clicking a room from the listing page.

**Root cause:** `useDiscountApproval()` was called **after** `if (!room) return ...` (line 345), violating React's Rules of Hooks. When room is null, the hook is skipped → different render order → crash.

**Fix (`src/pages/RoomDetail.tsx`):**
- Moved `const { isApproved } = useDiscountApproval()` to the top of the component with all other hooks (before any conditional returns)
- Removed duplicate call after the `if (!room)` block

**Commit:** `800f0f2`
