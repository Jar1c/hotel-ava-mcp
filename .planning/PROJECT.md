# Smart Hotel Reservation and Recommendation System

## What This Is

A smart hotel platform that uses AI-driven recommendations for guests and predictive analytics for management, built with React + Tailwind CSS frontend and Flask + Supabase backend.

## Core Value

Provide personalized room recommendations and predictive insights that increase bookings while optimizing hotel operations through data-driven decision making.
