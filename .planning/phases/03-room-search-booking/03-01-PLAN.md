# Plan 03-01: Room Search & Listing

## Goal
Guest can search for rooms and browse listings with filters, sort, and room cards.

## Requirements
- RSCH-01: Guest can search rooms by date range, guest count, and price range
- RSCH-02: Guest can view room listing as grid cards with image, price, and amenities

## Tasks

### Task 1: Mock Data
- Create `src/data/rooms.ts` with 8-10 mock rooms
- Each room: id, name, type, description, price, capacity, amenities[], images[], rating, reviews

### Task 2: Room Card Component
- Create `src/components/rooms/RoomCard.tsx`
- Image with carousel dots, price, name, capacity, rating, amenities preview
- Link to /rooms/:id

### Task 3: Search Filters
- Create `src/components/rooms/SearchFilters.tsx`
- Date range (DayPicker), guest count, price range (slider)
- Sort dropdown (Price Low-High, Price High-Low, Rating)

### Task 4: Rooms Page
- Rewrite `src/pages/Rooms.tsx`
- SearchFilters at top, RoomCard grid below
- Filter/sort logic with useState
- Responsive: 1 col mobile, 2 col tablet, 3-4 col desktop

## Verification
- [ ] Room cards display with images, prices, amenities
- [ ] Filters work: date, guests, price, sort
- [ ] Responsive layout at all breakpoints
- [ ] Click card navigates to /rooms/:id
